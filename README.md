## ⚡ Highlights & Engineering Features

- **Ink Dissolve WebGL Preloader**: Fluid GLSL ink mask dissolve transition syncing numerical asset decode counters (0% to 100%) before unveiling the stage.
- **Three.js 3D Physics Lanyard ID Badge**: Custom Verlet-physics ID card simulation with interactive cursor/touch drag-and-swing mechanics and authentic photo badge rendering.
- **Three.js Floating Travel 3D Gallery**: Curated aesthetic photography from countries visited (**🇨🇳 China, 🇲🇾 Malaysia, 🇸🇬 Singapura, 🇮🇩 Indonesia**) floating seamlessly in 3D camera space around typography.
- **Limelight Mechanical Drawer Navigation**: Dynamic spring-physics pull-down drawer (`TAP TO OPEN` / `Pull Down`) with tactile mechanical sound and route navigation.
- **AI Cinema Scroll-To-Scale Lab**: Pinned vertical scroll transformation scaling featured web architecture into full-width widescreen, flanked by infinite ambient video strip reels.
- **Mobile 3D Circular Cylinder Stage**: Kinetic touch-driven 3D carousel with perspective projection and focus transitions.
- **Bayer-Matrix Dither ASCII Ticker**: Real-time canvas procedural retro dot-matrix rendering of "Raffa Rizqi" with ambient wave oscillation.
- **WebGL Dappled Sunlight Shader**: Custom fragment shader computing procedural atmospheric sunlight and organic tree leaf shadows.

## 🛠️ Tech Stack & Architecture

- **Frontend Core**: Next.js 16.3.5 (Turbopack), React 19, TypeScript
- **3D Graphics & Shaders**: Three.js (r128), WebGL GLSL Shaders, Canvas 2D
- **Animation & Scrolling**: Lenis Smooth Scroll, Custom Inertial Drag, Spring Physics
